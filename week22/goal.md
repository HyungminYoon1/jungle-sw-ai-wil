# Week 22 - 개인 목표

> 기간: 2026-07-27 ~ 2026-07-30
>
> 성격: 취업 준비, 심화 과정 신청, 정글 수료 이후 계획 수립

---

## 1. 이번 주의 방향

Week 22는 지금까지의 경험을 채용 담당자와 면접관이 이해할 수 있는 형태로 정리하고, 
정글 심화 과정에서 보완할 역량을 구체적인 실행 계획으로 바꾸는 기간이다.

다음 네 가지를 우선한다.

1. 지원 가능한 이력서와 포트폴리오 기본안을 만든다.
2. Nodease에서 맡은 Knowledge/RAG 경험을 과장 없이 설명할 수 있게 정리한다.
3. 정글 심화 과정 3개월 학습 계획을 작성하고 신청한다.
4. 수료 이후에도 유지할 학습·지원·회고 루틴을 정한다.

## 2. 세부 목표

### 취업 자료 준비

- 지원 직무를 백엔드, AI 플랫폼, LLMOps 관련 직무로 정리한다.
- 이력서 첫 문장과 자기소개를 작성한다.
- Nodease 프로젝트의 문제, 역할, 접근, 결과와 한계를 한 페이지 안에서 설명한다.
- Knowledge/RAG의 권한, 문서 수명주기, Citation과 실행 시점 검증 경험을 핵심 사례로 정리한다.
- 코치 또는 동료에게 이력서와 프로젝트 설명에 대한 피드백을 한 번 이상 받는다.
- 피드백을 반영한 이력서 기본안을 완성한다.

### 면접 준비

- 1분 자기소개를 소리 내어 연습한다.
- Nodease의 기술 선택과 내 기여 범위를 설명할 수 있게 준비한다.
- Knowledge/RAG 예상 질문과 답변을 정리한다.
- 프로젝트에서 직접 확인한 사실과 AI 에이전트의 결과 보고에 의존한 부분을 구분한다.
- 손코딩 문제를 최소 2개 풀고 풀이와 시간 복잡도를 말로 설명한다.
- 모르는 질문을 받았을 때 아는 범위와 추론을 구분해 답하는 연습을 한다.

### 심화 과정 준비

- 3개월 뒤의 목표 상태를 먼저 정의한다.
- 학습 기술의 우선순위와 선정 이유를 작성한다.
- 월별 결과물과 취업 활동 계획을 포함한다.
- AI를 활용하더라도 코드와 테스트를 직접 읽고 설명하는 검증 원칙을 계획에 넣는다.
- 학습 계획서를 PDF로 변환해 제출 가능한 상태로 만든다.
- 수요일 자정 전 심화 과정 참가신청서를 제출한다.

### 수료 이후 전환

- 공개 저장소와 포트폴리오에서 비밀값과 개인정보 노출 여부를 확인한다.
- 배포 링크, GitHub README와 프로젝트 설명 자료의 현재 상태를 확인한다.
- 수료 후 첫 주의 학습, 지원과 면접 준비 일정을 정한다.
- 매주 WIL과 주간 회고를 기록하고 유지할 방법을 정한다.

## 3. 완료 기준

| 목표 | 완료 기준 |
|---|---|
| 이력서 | 지원 가능한 기본안 1개와 직무별 수정 기준이 있다. |
| 포트폴리오 | Nodease의 문제, 기여, 기술 선택, 결과와 한계를 설명한다. |
| 면접 | 1분 자기소개와 프로젝트 예상 질문에 두괄식으로 답할 수 있다. |
| 손코딩 | 손코딩 기술 면접 예시를 보고, 당사자가 되었다고 상상하며 시뮬레이션. 시간 복잡도와 개선 방향을 설명할 수 있다. |
| 심화 과정 | 참가신청서와 PDF 학습 계획서를 기한 안에 제출한다. |
| 보안 | 공개 자료에 credential, 개인정보와 내부 접근 정보가 없음을 확인한다. |
| 수료 이후 | 첫 1주와 3개월의 실행 계획 등이 문서로 남아 있어야 한다. |

## 4. 우선순위

1. 제출 기한이 있는 심화 과정 신청과 학습 계획서
2. 코치 피드백을 받을 이력서와 프로젝트 설명
3. 기술면접과 손코딩 준비
4. 수료 후 세부 학습 자료 정리

## 5. 이번 주에 하지 않을 일

- 새로운 대규모 기능을 시작하지 않는다.
- 이력서를 화려하게 보이게 하기 위해 검증하지 않은 성과를 추가하지 않는다.
- 모든 기술을 한 번에 깊게 공부하려 하지 않는다.
- 실제 이력서 원본, 연락처와 지원 기업별 개인정보를 공개 저장소에 올리지 않는다.
