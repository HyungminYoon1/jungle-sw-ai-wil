# 문제
4. 프로세스 A는 디스크에서 파일을 읽어 네트워크를 통해 외부로 전송하고자 한다. 이 과정에서 사용되는 시스템 콜을 기능별로 나누어 설명하시오. (Pintos에 Network 가 있다고 가정)

# 답변
잘 모르겠습니다.
SYS_OPEN으로 디스크에 있는 파일을 열고, SYS_FILESIZE로 데이터 크기를 확인하고, SYS_READ로 데이터를 읽고, SYS_WRITE로 버퍼에 데이터를 올리며, 이후 소켓을 통해 데이터를 다른 PC로 전송할 것 같습니다.

# 정답
프로세스 A가 디스크의 파일을 네트워크로 전송하려면 다음과 같은 시스템 콜이 사용된다.

1. 파일 열기
- SYS_OPEN: 디스크에 있는 파일을 열고 파일 디스크립터를 얻는다.

2. 파일 읽기
- SYS_READ: 열린 파일 디스크립터에서 데이터를 읽어 사용자 버퍼에 저장한다.

3. 네트워크 연결 준비
- socket: 네트워크 통신을 위한 소켓을 생성한다.
- connect: 외부 서버 또는 다른 PC와 연결한다.

4. 네트워크 전송
- send 또는 SYS_WRITE: 읽어 온 파일 데이터를 소켓을 통해 네트워크로 전송한다.

5. 자원 정리
- SYS_CLOSE: 파일 디스크립터와 소켓을 닫는다.
