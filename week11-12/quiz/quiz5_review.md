# 문제
5.  램(RAM)과 디스크 간의 페이징 과정에서 보조 페이지 테이블(Supplemental Page Table, SPT)이 사용되는 이유를 서술하시오.

# 답변
페이지 테이블은 CPU가 MMU에게 바로 접근을 지시해야할 페이지-프레임 관계 정보만 담고 있고, 부가적인 정보는 담고 있지 않습니다.
페이지 폴트는 접근 권한이 없거나 시스템에 오류가 발생했을 때 발생하기도 하지만, lazy load을 적용할 경우에는 페이지-프레임 관계를 곧바로 메모리에 로드하지 않기 때문에 데이터의 최초 로드시에 정상적으로 발생합니다. 
이 때 보조 페이지 테이블(Supplemental Page Table)을 이용하여 페이지 폴트가 발생한 페이지-프레임 다시 매핑을 수정하고, 페이지와 매핑된 프레임을 찾아 읽기/쓰기를 하는 과정이 이어서 정상적으로 동작하도록 합니다.

# 정답
보조 페이지 테이블(SPT)은 일반 페이지 테이블에 담기지 않는 페이지의 부가 정보를 관리하기 위해 사용된다.

일반 페이지 테이블은 현재 메모리에 올라와 있는 가상 페이지와 물리 프레임의 매핑 정보를 주로 저장한다. 하지만 lazy loading이나 swap out된 페이지처럼 아직 RAM에 없거나 디스크에 있는 페이지에 대해서는, 해당 페이지가 파일의 어느 위치에 있는지, swap 영역에 있는지, 읽기/쓰기 권한은 무엇인지 등의 정보가 필요하다.

페이지 폴트가 발생하면 운영체제는 SPT를 조회하여 이 접근이 유효한 접근인지 확인하고, 유효하다면 파일 또는 swap 영역에서 페이지를 읽어와 프레임에 적재한 뒤 페이지 테이블을 갱신한다.
