# 문제
3. 페이지 단위 메모리 관리 관점에서 lazy loading의 장점과 단점을 서술하시오.

# 답변
- 장점: 당장 필요하지 않은 내용을 메모리에 미리 올리지 않기 때문에 메모리 공간을 절약할 수 있습니다.
- 단점: 디스크에서 메모리로 로딩을 하는데 시간이 걸립니다.

# 정답
- 장점: 필요한 페이지가 실제로 접근될 때만 메모리에 적재되므로, 불필요한 페이지를 미리 올리지 않아 메모리 사용량을 줄일 수 있다. 또한 프로그램 시작 시간이 짧아질 수 있다.
- 단점: 처음 접근하는 페이지가 메모리에 없으면 page fault가 발생하고, 디스크에서 해당 페이지를 읽어와야 하므로 지연 시간이 발생한다.
