# 문제
1. 운영체제 커널을 보호하기 위한 조치를 1개 이상 설명하시오.

# 답변
- 접근 권한을 설정하여 사용자 프로세스가 운영체제의 커널 영역에 직접 접근하지 못하게 합니다.
- 메모리에서 커널영역이 할당되는 주소에 랜덤 값을 반영하여 시작 주소와 끝 주소를 알지 못하게 합니다.

# 정답
- 사용자 모드와 커널 모드를 분리하여 사용자 프로세스가 커널의 특권 명령을 직접 실행하지 못하게 합니다.
- 페이지 테이블/MMU를 통해 커널 메모리 영역에 대한 사용자 프로세스의 접근 권한을 제한합니다.
- 커널 기능은 시스템 콜처럼 정해진 인터페이스를 통해서만 접근하도록 합니다.
- KASLR을 사용해 커널이 메모리에 적재되는 주소를 무작위화하여 공격자가 커널 주소를 예측하기 어렵게 합니다.
