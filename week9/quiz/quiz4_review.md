# 문제
4. 데드락의 개념에 대해 설명하시오 .

# 답변
데드락이란 락을 가진 2개 이상의 스레드가 서로 다른 스레드가 갖고 있는 락을 취하려고 할 때 사이클을 만들면서 사이클 내의 어느 스레드도 락을 얻거나 반환하지 못하게 되는 교착 상태를 의미합니다.

# 정답
데드락(deadlock)은 둘 이상의 프로세스나 스레드가 서로 상대방이 가진 자원을 기다리면서 더 이상 진행하지 못하는 교착 상태를 말한다.

예를 들어 스레드 A가 lock1을 획득한 상태에서 lock2를 기다리고, 스레드 B가 lock2를 획득한 상태에서 lock1을 기다리면 두 스레드는 서로가 락을 해제하기만 기다리게 된다. 이 경우 어느 쪽도 진행할 수 없으므로 데드락이 발생한다.

데드락은 일반적으로 다음 네 가지 조건이 동시에 만족될 때 발생한다.

1. 상호 배제: 한 자원은 한 번에 하나의 스레드만 사용할 수 있다.
2. 점유와 대기: 스레드가 이미 자원을 가진 상태에서 다른 자원을 기다린다.
3. 비선점: 다른 스레드가 가진 자원을 강제로 빼앗을 수 없다.
4. 순환 대기: 스레드들이 서로가 가진 자원을 원형으로 기다린다.
