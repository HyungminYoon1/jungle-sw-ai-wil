# 문제
2. MLFQS를 사용하는 가장 큰 이유에 대해 설명하시오.

# 답변
우선순위가 높은 작업을 먼저 자주 실행하면서도, 우선순위가 낮은 작업을 아사시키지 않는 스케줄링을 구현하기 위함입니다.

# 정답
MLFQS를 사용하는 가장 큰 이유는 스레드의 우선순위를 동적으로 조정하여 공정하고 효율적인 CPU 스케줄링을 하기 위해서입니다.

CPU를 많이 사용하는 스레드는 우선순위를 낮추고, 최근에 CPU를 적게 사용했거나 대기하던 스레드는 우선순위를 높여서 특정 스레드가 CPU를 독점하지 못하게 합니다. 이를 통해 응답성을 높이고, 낮은 우선순위 스레드의 아사를 방지할 수 있습니다.
