# 문제
1. 커널 모드에서 실행될 수 있는 작업의 예를 들고, 이러한 작업들이 사용자 모드에서 실행되지 않는 이유를 설명하시오.

# 답변
커널 모드에서는 운영체제의 커널 코드가 실행됩니다. 여기에서 현재 실행중인 스레드를 중단/교체하거나, CPU 레지스터의 데이터를 변경하거나, OS를 종료시키는 등 시스템 전체에 영향을 줄 수 있는 높은 권한을 갖고 있기 때문에, OS의 안정성 유지를 위해 일반 사용자 프로세스의 사용자 모드에서는 임의로 커널 코드나 커널 스레드를 조작할 수 없도록 제한합니다.

# 정답
커널 모드에서 실행될 수 있는 작업은 예를 들어 입출력 장치 제어, 메모리 관리, 프로세스/스레드 스케줄링, 인터럽트 처리, 파일 시스템 접근, CPU 제어 명령 실행 등이 있습니다.

이 작업들은 시스템 전체의 자원과 안정성에 직접 영향을 주기 때문에 사용자 모드에서 임의로 실행할 수 없습니다. 사용자 프로그램이 직접 실행하면 메모리 침범, 장치 오작동, 다른 프로세스 손상, 운영체제 중단 같은 문제가 생길 수 있으므로, 사용자 모드에서는 시스템 콜을 통해 커널에 요청하는 방식으로만 수행됩니다.
