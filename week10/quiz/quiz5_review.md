# 문제
5.  #ifdef 함수의 장단점을 서술하라.

# 답변
- 장점: 같은 코드베이스를 기반으로 조건식을 적용하여 필요할 때 원하는 코드를 적용할 수 있습니다.
- 단점: 코드가 지저분해 보입니다.

# 정답
#ifdef는 전처리 지시문으로, 특정 매크로가 정의되어 있을 때만 해당 코드를 컴파일하도록 만드는 기능입니다.

장점은 하나의 코드베이스에서 환경, 옵션, 디버그 여부에 따라 다른 코드를 선택적으로 컴파일할 수 있다는 점입니다. 예를 들어 운영체제별 코드, 테스트용 코드, 디버그 로그 등을 필요할 때만 포함할 수 있어 이식성과 설정 유연성이 좋아집니다.

단점은 #ifdef가 많아지면 코드 흐름을 읽기 어려워지고 유지보수가 어려워진다는 점입니다. 실제로 어떤 코드가 컴파일되는지 빌드 옵션에 따라 달라지므로 버그를 찾기 어려울 수 있고, 사용하지 않는 분기 코드가 오래 방치되어 깨질 위험도 있습니다.
