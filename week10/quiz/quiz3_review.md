# 문제
3. fork로 프로세스를 생성할때와 exec로 생성할때의 차이점을 설명 하시오. 

# 답변
pintos 에서 fork는 현재 프로세스를 복사해서 새 프로세스를 만들어 실행하고, exec는 현재 프로세스가 실행하던 내용을 다른 프로그램으로 교체하여 실행합니다.

# 정답
fork는 현재 실행 중인 프로세스를 복제해서 새로운 자식 프로세스를 만드는 것입니다. 자식 프로세스는 부모의 주소 공간, 파일 디스크립터, 실행 상태 등을 복사해서 시작하며, 부모와 자식은 서로 다른 PID를 가집니다.

반면 exec는 새 프로세스를 만드는 것이 아니라, 현재 프로세스의 메모리 공간을 새로운 프로그램으로 교체하는 것입니다. 즉 기존 프로세스의 PID는 유지되지만, 실행 중이던 코드와 데이터는 사라지고 새 실행 파일의 코드와 데이터로 바뀝니다.

정리하면, fork는 프로세스 복제, exec는 현재 프로세스의 프로그램 교체입니다. 보통 새 프로그램을 실행할 때는 fork로 자식 프로세스를 만든 뒤, 자식에서 exec를 호출합니다.
